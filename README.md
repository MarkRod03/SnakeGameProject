# SnakeGameProject

Created a basic Snake Game using C that can be played in the terminal. The game creates a border which reflects the size of the terminal where food is placed into the map one at a time. The food is represented with a number that indicates how many extra units will be added to the snake if the food is picked up. The food is also given a random number indicating how long it will remain on the board until it disappears and a new food item is placed. The snake also grows from the front instead of the back.

This was Created in Fall 2023 for the C Programming Class at CCSU (with Fexia and Michael​).
